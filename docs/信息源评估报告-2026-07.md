# 国内手游买量信息源评估报告

调研日期：2026-07-22 ｜ 调研方式：robots.txt 实测（curl）+ 免登录访问实测（curl / Firecrawl basic & stealth 代理）+ TikHub OpenAPI 规格全量解析（1023 个端点）+ web 检索交叉验证
红线约束：不做带登录态的违 ToS 抓取；robots 明确 Disallow 的路径不抓。

## 二、逐家评估

### A. 玩家口碑 / UGC

#### A1. 百度贴吧（游戏吧）——放弃自动化，P2 人工导入
- **内容价值**：高。核心玩家吐槽/攻略/版本讨论密度大，是「玩家痛点」的一手来源，尤其传奇/仙侠/SLG 等买量大品类的吧氛围极其真实。
- **接入实测**：无公开 API。robots.txt 未对通用 UA 全站封禁（仅对 Baiduspider/Googlebot 等禁 `/club/`、`/f/search` 等少数路径），**但实际有强反爬**：数据中心 IP + 浏览器 UA 直接 403「百度安全验证」；Firecrawl stealth 代理同样 403。深度翻页与部分楼层需登录态。
- **反爬强度**：极强（验证码墙 + IP 信誉体系）。TikHub 29 平台不含贴吧。
- **建议**：**放弃自动化**。高价值精华帖由人工浏览后经既有 `import-reviews` 通路手工导入。P2。

#### A2. NGA 玩家社区——放弃自动化，P2 人工导入
- **内容价值**：高（中重度玩家、数值党、二游/暴雪系/舰船类讨论质量全网最高）。
- **接入实测**：访客访问版面直接返回「访客不能直接访问」（实测 bbs.nga.cn / ngabbs.com fid=428 均拦截），**读帖即需登录**，无公开 API。robots 本身宽松，但登录墙使其无意义。
- **反爬强度**：登录墙即最强反爬；带登录态抓取直接违 ToS，踩红线。
- **建议**：**放弃自动化**，人工摘录高楼层讨论导入。P2。

#### A3. 微博（游戏官微 + 超话）——P0，走 TikHub
- **内容价值**：高。官微=版本活动/公告的第一现场；超话+评论=玩家情绪浓度最高的地方；热搜=题材热度信号。
- **接入实测**：`m.weibo.cn` robots 对 `User-agent: *` 全站 Disallow（仅放行百度/谷歌等具名蜘蛛）→ 自建抓取踩 robots 红线；weibo.com 明确对 AI 爬虫（Bytespider/DeepSeek/ChatGPT-User 等）设限。**但 TikHub 已覆盖微博 64 个端点**，用付费聚合方绕开自建抓取的合规负担。
- **反爬强度**（自建）：强。（TikHub 侧）：无感。
- **建议**：**P0**，TikHub 连接器。关键端点见第四节。

#### A4. 好游快爆（4399 系，3839.com）——P1，受限连接器
- **内容价值**：中高。国内安卓手游玩家社区+评分，评分人数大（示例页 4.5 万人评分），对「玩家评价/爽点痛点」是 TapTap 的重要补充（用户更下沉、更偏休闲/联运盘）。
- **接入实测**：游戏详情页（`m.3839.com/a|b|c/{id}.htm`）**免登录可访问**，含总评分、评分人数和页面内嵌精选评价；但 robots（www 与 m 同）**明确 Disallow `/comment/`、`/cdn/comment/` 与所有 `?` 查询串** → 评论翻页接口属红线，不能抓全量评论。无公开 API，App 接口需签名（灰色，不做）。
- **反爬强度**：中低（详情页普通 UA 可直取，`www.3839.com/a/` 目录页 403，个别路径有防护）。
- **建议**：**P1**。做「聚合评分连接器」：仅取详情页呈现的评分/人数/页面内嵌评价（类似已有 TapTap JSON-LD 方案）；全量评论不做。

#### A5. B站 / TapTap / 小红书
已接入（bili CLI 热评 / TapTap JSON-LD+Hermes 导入 / TikHub 小红书），本次跳过。

### B. 官方广告平台免费工具

#### B1. 巨量创意·灵感库（cc.oceanengine.com，原 creative.oceanengine.com）——P1 受限 + 人工
- **内容价值**：极高（对买量写作是最贴题的库）：热门素材榜、热门落地页、行业洞察、内容洞察，且**内容行业/达人垂类均有「游戏」筛选**。
- **接入实测**：免登录可看到「热门素材（星图）」首屏榜单（标题/热度/达人/粉丝数，实测约 20 条），继续翻页与**完整广告素材库、落地页详情、行业洞察数据需登录巨量引擎账号**（页面明示「登录查看更多」）。无公开 API；oceanengine.com robots 为空（未禁止）。
- **反爬强度**：免登录部分中等（SPA、字节风控）；登录后自动化=带登录态抓取，踩红线。
- **建议**：**P1 拆两路**：(a) 免登录首屏热门素材榜做轻量轮询连接器（每日一次，只取标题+热度+垂类，作为「素材套路风向」信号）；(b) 完整素材库由投手人工登录浏览，把值得存档的套路描述人工导入。

#### B2. 巨量算数（trendinsight.oceanengine.com，已更名「抖音指数」）——P2 人工
- **内容价值**：高。关键词搜索/内容指数=题材热度的权威口径；算数报告有行业月报。
- **接入实测**：站点在线（title：抖音指数(原巨量算数)），但**算数指数查询需抖音扫码登录**（实测访问 arithmetic-index 被重定向到创作者中心登录页）；算数榜单/报告页部分免登录可浏览。无公开 API。
- **反爬强度**：登录墙 + 字节风控，强。
- **建议**：**P2**。指数类信息人工自查后把结论手工导入；替代信号用 TikHub 抖音热搜/话题榜（免登录墙、可自动化）覆盖 80% 需求。

#### B3. 腾讯广告创意中心——放弃自动化
- **接入实测**：无独立公开素材库。创意素材功能在广告主后台（ad.qq.com 客户工作台→创意资产），**全量在 sso.e.qq.com 登录墙后**。
- **建议**：**放弃**自动化；投手日常自用，重要发现人工导入。

#### B4. 快手磁力创想 / 磁力引擎素材库——放弃自动化
- **接入实测**：cc.e.kuaishou.com 已 302 到 kc.kuaishou.com「磁力开创」（AI 创意生产平台），**功能全部在登录后**，公开页仅营销首页。
- **建议**：**放弃**自动化。快手侧素材/口碑信号改用 TikHub 快手端点（P0）补足。

### C. 数据榜单

#### C1. 七麦数据（qimai.cn）——放弃自动化
- **内容价值**：中（iOS 榜单/关键词指数对竞品监控有用）。
- **接入实测**：**未登录几乎无数据**（榜单页直接显示「登录/注册后可查看更多数据」）；robots.txt 对非浏览器 UA 直接 403；其 XHR 接口带签名参数（`analysis`），是圈内著名的强反爬案例；官方 API 为付费「API 合作」。
- **反爬强度**：极强（签名+设备指纹+登录墙）。
- **建议**：**放弃**自动化。如确需 iOS 榜单，用已有 iTunes RSS/官方接口（注意 10rpm 限速）替代；七麦结论人工导入。

#### C2. 点点数据（diandian.com）——P2 人工导入报告
- **内容价值**：中高。覆盖 AppStore/GP/安卓/TapTap/Steam 等 8 平台；**免费公开的行业报告质量不错**（首页可直接看，如《2026 中国上市游戏公司 AI 渗透报告》《2026 Q1 竞技手游体验评估》）。
- **接入实测**：数据产品在 app.diandian.com 登录墙后；公开侧只有 /reports 报告页；robots Disallow `/post/*`。无公开 JSON 接口。
- **建议**：**P2**。每月人工浏览 /reports，把与买量题材相关的报告要点导入知识库。

#### C3. 蝉大师（chandashi.com）——放弃
- **接入实测**：公司已整体转向「品牌内容营销与电商增长」（蝉妈妈/蝉魔方系），官网 SPA，ASO 数据产品边缘化且在登录墙后。
- **建议**：**放弃**。历史 ASO 场景已被七麦/点点覆盖，而这两家也都以人工为主。

## 四、接入路线建议

### 自动化连接器清单（按优先级）
1. **P0 TikHub-抖音**：关键词搜视频→取热门视频评论→评论词云端点辅助提炼爽点痛点；billboard 话题榜做题材热度日报。语义映射沿用 `player_opinion` / `creative_insight`。
2. **P0 TikHub-微博**：游戏名+超话搜索、官微 feed、帖子评论；热搜榜做热点信号。
3. **P0 TikHub-快手**：搜索+评论，补足快手系买量盘的口碑。
4. **P0 手游那点事 RSS**：`http://www.nadianshi.com/feed`，半小时/次轮询，入库带原文链接引用。
5. **P0 GameLook 列表页轮询**：首页+分类页解析（WordPress 结构稳定）；注意从新加坡服务器直连可能被过滤，需实测，必要时经代理（生产环境已有 WG 通路）。
6. **P0 游戏陀螺 sitemap 轮询**：`sitemap-index.xml` 当日增量。
7. **P1 TikHub-wechat_mp**：接游戏葡萄、DataEye 游戏观察（需先解析各公众号 biz 参数）；竞核公众号可与官网二选一。
8. **P1 竞核列表页轮询**：`cgames.com/channels/2.html`（热点）+ `/channels/4.html`（快报）。
9. **P1 好游快爆聚合评分连接器**：游戏详情页评分/人数/内嵌评价，参考 TapTap 连接器实现；**不碰 /comment/ 路径**。
10. **P1 巨量创意免登录榜单**：每日抓一次免登录首屏「热门素材（游戏垂类）」，只存标题/热度/垂类作风向信号。

### 人工导入清单（不自动化）
- 巨量创意完整素材库、巨量算数（抖音指数）指数查询 → 投手自用账号人工浏览，结论经 import 通路导入
- 腾讯广告创意中心、快手磁力开创 → 同上
- 点点数据免费报告（/reports，月度） → 人工摘要导入
- 贴吧精华帖、NGA 高楼层讨论 → 人工摘录导入
- 七麦 → 原则上放弃；确需 iOS 榜单用 iTunes 官方接口（10rpm 限速）替代

### 明确放弃
- 蝉大师（业务转向，无增量价值）
- 贴吧/NGA/微博的**自建**抓取（反爬/登录墙/robots 三重不可行）
- 三家广告平台登录后台的任何自动化

## 五、风险与合规备注

1. **robots 红线已核**：m.weibo.cn 全站 Disallow（自建抓取不做，走 TikHub）；好游快爆 `/comment/`、`/cdn/comment/`、`?` 查询串 Disallow（连接器只取详情页）；点点 `/post/*` Disallow；其余拟接站点（nadianshi/gamelook/youxituoluo/cgames）robots 均无限制或无 robots。
2. **登录态红线**：巨量算数、腾讯创意中心、磁力开创、七麦、NGA 全部登录墙——一律不做带登录态自动化，只允许人工浏览+手工导入。
3. **TikHub 依赖风险**：UGC 层 4 个 P0 全押在 TikHub 上，属单点依赖（供应商风控、端点变更、余额耗尽都会同时打击四路）。缓解：连接器层沿用 `tikhub.ts` 统一客户端便于熔断与告警；余额监控；B站保留 bili CLI 自有通路作为「非 TikHub 样本」。
4. **TikHub 本身的性质**：它是对各平台的第三方逆向聚合，法律上属灰色（与小红书接入时的判断一致，未新增风险面）；我们不落地平台原始内容全文对外分发，知识库内保留摘录+出处链接，风险敞口可控。
